Research & Engineering Prototype

MedNourish V1.0

An end-to-end multimodal screening architecture exploring tabular gradient boosting, curated knowledge retrieval, and mobile edge computer vision.

Important Academic & Research Disclaimer: MedNourish is an educational and engineering prototype. It is strictly NOT a certified medical diagnostic device or clinical decision-support tool. It does not provide medical diagnoses, treatment prescriptions, or emergency triage. Real clinical evaluation requires consultation with qualified healthcare professionals and accredited laboratory diagnostics.

1. Overview & Architecture

MedNourish integrates multiple clinical AI patterns to evaluate nutritional wellness without opaque black boxes:

  • Deterministic Symptom Matching: Rigorous inverted-index set intersections and BM25/TF-IDF mapping across curated anatomical manifestations (Eyes, Hair, Lips, Nails, Skin, Tongue).
  • Leakage-Aware Tabular Screening: Honest comparative benchmarks evaluating blood biomarker models versus non-invasive symptom-only screening.
  • Edge Computer Vision: Transfer-learned MobileNetV2 vision models converted to TFLite for local in-browser / edge anatomical evaluation.
  • Privacy-Preserving Local Operation: Offline-capable architecture designed with field-level encryption, role-based isolation, and zero unauthorized third-party telemetry.

3. Running Locally

To run the development stack locally in SQLite mode:

1. Backend (FastAPI):

cd backend python -m venv .venv # On Windows: .venv\Scripts\activate # On Linux/macOS: source .venv/bin/activate pip install -r requirements.txt cp ../.env.example .env export DB_MODE=sqlite python -m uvicorn app.main:app --reload --port 8000

2. Frontend (React 19 + TypeScript + Vite):

cd frontend npm ci npm run dev
